# Interview transcripts

Store the full conversation of each simulated interview here, one file per session, for example `S1_owner-ceo.md`.

Each file starts with:

```
Session: S-1 | Role: Owner and CEO (AI simulation)
Model: [name] | Date: [yyyy-mm-dd] | Interviewer: [name] | Note-taker: [name]
```

Then paste the conversation, with the interviewer lines marked "Interviewer:" and the AI lines marked with the persona name.

Why: the transcripts are the evidence for the interviews. Every requirement in the catalog whose source is an interview can be traced back to a transcript.
