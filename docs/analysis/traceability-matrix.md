Each requirement is traced to the user story that implements it, then to the solution element (table, measure, report) and the test that proves it. In Sprint 0 only the first columns can be filled. The person who finishes a story updates the "Solution element" and "Test" cells in the same pull request. A story is not Done until its row is updated (part of the Definition of Done).
