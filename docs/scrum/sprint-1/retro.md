# Sprint 1 Retrospective

**Sprint Goal:** Проектировать архитектуру (C4/ERD/ADR), развернуть БД со слоями хранения, сгенерировать синтетические данные с дефектами и загрузить первый источник — заказы.

## Что прошло хорошо
- Генерация синтетических данных завершена в срок.
- Архитектурные артефакты (C4‑диаграммы, ERD) готовы к демонстрации.
- ADR подготовлены вовремя, что ускорило принятие технологических решений.
- Команда успешно организовала процесс загрузки заказов в staging‑слой.

## Что можно улучшить
- Координация работы с инструментами для диаграмм заняла больше времени, чем планировалось.
- При добавлении больших CSV‑файлов возникали конфликты в Git; стоит добавить `.gitattributes` для бинарных файлов.
- Тесты для скрипта загрузки заказов были минимальны; рекомендуется расширить набор проверок.

- [ ] Добавить автоматическую валидацию схем CSV (schema‑check).
